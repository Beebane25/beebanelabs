1. Aktifkan GitHub Pages

GitHub Pages adalah hosting gratis yang menyediakan SSL otomatis dan bandwidth unlimited. Cocok untuk website statis seperti IoTHub.

1 Buka GitHub Pages Settings
https://github.com/Beebane25/iothub/settings/pages
2 Konfigurasi Source
  1. Source: pilih "Deploy from a branch"
  2. Branch: pilih "main" / "/ (root)"
  3. Klik "Save"
3 Tunggu Deployment
  1. Tunggu 1-2 menit
  2. Refresh halaman → lihat status "Your site is live at..."
  3. Klik link untuk cek website
✅ Website Aktif! URL: https://beebane25.github.io/iothub/
SSL: otomatis (https)
Bandwidth: unlimited
Cost: GRATIS selamanya
⚠️ Catatan Penting Setelah deploy, ganti URL di sitemap.xml dari https://iothub.id ke URL GitHub Pages kamu (atau domain custom setelah step 2).

2. Beli & Hubungkan Domain Custom

Domain custom (contoh: iothub.id) membuat website terlihat profesional dan mudah diingat.

2.2 Setup Cloudflare (Recommended)

1 Buat Akun Cloudflare
  1. Buka https://dash.cloudflare.com
  2. Daftar akun gratis
2 Tambah Domain
  1. Klik "Add a site"
  2. Masukkan domain (contoh: iothub.id)
  3. Pilih plan Free
  4. Cloudflare akan scan DNS record
3 Ganti Nameserver di Registrar
  1. Cloudflare akan kasih 2 nameserver (contoh: aria.ns.cloudflare.com)
  2. Login ke registrar domain (Niagahoster/Domainesia)
  3. Menu: Domain → Nameserver / DNS
  4. Ganti nameserver ke yang Cloudflare berikan
  5. Simpan & tunggu propagasi (1-24 jam)
4 Tambah DNS Record di Cloudflare
  1. Buka Cloudflare → pilih domain → DNS → Records
  2. Klik "Add record"
  3. Isi:
    • Type: CNAME
    • Name: @
    • Target: beebane25.github.io
    • Proxy: ON (biru)
  4. Simpan
5 Hubungkan ke GitHub Pages
  1. Buka https://github.com/Beebane25/iothub/settings/pages
  2. Custom domain: masukkan iothub.id
  3. Klik "Save"
  4. Centang "Enforce HTTPS"
✅ Domain Aktif! Website sekarang di: https://iothub.id
SSL: otomatis dari Cloudflare

3. Submit ke Google Search Console

Google Search Console membantu Google menemukan dan meng-index halaman website kamu.

1 Buka Google Search Console
https://search.google.com/search-console
2 Tambah Property
  1. Login akun Google
  2. Klik "+ Property" (kiri atas)
  3. Pilih "Domain"
  4. Masukkan: iothub.id
3 Verifikasi via DNS
  1. Google akan kasih TXT record untuk verifikasi
  2. Buka Cloudflare → DNS → Records
  3. Tambah record baru:
    • Type: TXT
    • Name: @
    • Content: google-site-verification=XXXXX (dari Google)
    • TTL: Auto
  4. Klik "Verify" di Search Console
4 Submit Sitemap
  1. Di Search Console → Sitemaps (kiri)
  2. Masukkan: https://iothub.id/sitemap.xml
  3. Klik "Submit"
  4. Request indexing untuk homepage
5 Submit Halaman Penting
  1. URL Inspection → masukkan URL → Request Indexing
  2. Submit minimal 5 halaman pertama:
https://iothub.id/
https://iothub.id/articles/esp32-fundamentals.html
https://iothub.id/articles/mqtt-protocol.html
https://iothub.id/articles/mikrotik-routing.html
https://iothub.id/articles/lora-communication.html

6. Apply Google AdSense

Google AdSense membayar kamu setiap kali pengunjung mengklik iklan di website.

6.1 Syarat yang Sudah Terpenuhi

  • 21+ artikel original, 10.000+ baris konten
  • Privacy Policy, Terms, About, Contact, Disclaimer
  • robots.txt + sitemap.xml
  • Responsive design (mobile-friendly)
  • SSL/HTTPS aktif
  • Navigasi berfungsi dengan baik
  • Slot iklan sudah disiapkan di HTML
  • Domain custom (setelah step 2)

6.2 Yang Perlu Dipastikan

  • Umur domain minimal 1 bulan
  • Minimal 50-100 pengunjung/hari
  • Tidak ada konten pelanggaran hak cipta
  • SSL aktif (https://)

6.3 Cara Apply

1 Buka Google AdSense
https://www.google.com/adsense
2 Isi Formulir
  1. Login akun Google
  2. Klik "Get started"
  3. URL website: https://iothub.id
  4. Bahasa: Indonesia
3 Isi Informasi
  1. Negara: Indonesia
  2. Zona waktu: WIB (GMT+7)
  3. Nama: sesuai KTP
  4. Alamat: sesuai KTP
  5. Nomor HP: aktif
4 Verifikasi
  1. Email: otomatis terverifikasi
  2. Telepon: via SMS atau telepon
  3. Alamat: Google akan kirim surat berisi PIN ke alamat KTP
5 Tunggu Review
  1. Proses review: 1-14 hari
  2. Google akan cek: konten, traffic, kebijakan privasi
  3. Jika disetujui: email notifikasi + dashboard aktif
  4. Jika ditolak: perbaiki masalah yang disebutkan, apply lagi

7. Pasang Kode Iklan AdSense

Setelah disetujui, pasang kode iklan di slot yang sudah disiapkan.

1 Buat Unit Iklan
  1. Login AdSense → Ads → By ad unit
  2. Buat unit iklan:
    • Display ads (banner responsif)
    • In-article ads (antara paragraph)
    • In-feed ads (di antara daftar artikel)
  3. Copy kode iklan dari setiap unit
2 Pasang di HTML
  1. Buka file HTML dengan text editor
  2. Cari komentar: <!-- AdSense: ... -->
  3. Ganti dengan kode iklan dari Google
<!-- ADSENSE: Top Banner -->
<ins class="adsbygoogle"
     style="display:block"
     data-ad-client="ca-pub-XXXXXXXXXXXXXXXX"
     data-ad-slot="XXXXXXXXXX"
     data-ad-format="auto"
     data-full-width-responsive="true"></ins>
<script>(adsbygoogle = window.adsbygoogle || []).push({});</script>
📍 Posisi Iklan yang Efektif 1. Banner atas (setelah hero section) — CTR tinggi 2. In-article (setiap 3-4 paragraph) — natural placement 3. Sidebar (jika ada) — secondary income 4. Banner bawah (sebelum footer) — secondary income
⚠️ Aturan AdSense - JANGAN klik iklan sendiri - JANGAN suruh orang klik iklan - JANGAN taruh iklan di popup - JANGAN manipulasi posisi iklan
Pelanggaran = akun dibanned permanen!

9. Setup Email Notification

Dapatkan notifikasi saat ada subscriber baru atau pembayaran masuk.

9.1 Opsi 1: EmailJS (Recommended)

1 Buat Akun EmailJS
  1. Buka https://www.emailjs.com
  2. Daftar gratis
  3. Add Email Service (pilih Gmail atau SMTP)
  4. Create Email Template
  5. Copy: Service ID, Template ID, Public Key
2 Tambahkan ke JavaScript
  1. Tambahkan script EmailJS di index.html:
<script src="https://cdn.jsdelivr.net/npm/@emailjs/browser@3/dist/email.min.js"></script>
<script>
  emailjs.init("YOUR_PUBLIC_KEY");

  // Kirim notifikasi saat ada subscriber baru
  function notifyNewSubscriber(email) {
    emailjs.send("YOUR_SERVICE_ID", "YOUR_TEMPLATE_ID", {
      to_email: "iothub@gmail.com",
      subscriber_email: email
    });
  }
</script>

9.2 Opsi 2: Telegram Bot

1 Buat Bot Telegram
  1. Buka Telegram → cari @BotFather
  2. Kirim /newbot
  3. Ikuti instruksi → dapat bot token
2 Dapatkan Chat ID
  1. Kirim pesan apapun ke bot kamu
  2. Buka: https://api.telegram.org/botYOUR_TOKEN/getUpdates
  3. Cari chat.id → itu chat ID kamu
3 Tambahkan di server.py 
import requests

TELEGRAM_TOKEN = "YOUR_BOT_TOKEN"
TELEGRAM_CHAT_ID = "YOUR_CHAT_ID"

def notify_telegram(message):
    url = f"https://api.telegram.org/bot{TELEGRAM_TOKEN}/sendMessage"
    requests.post(url, json={
        "chat_id": TELEGRAM_CHAT_ID,
        "text": message,
        "parse_mode": "HTML"
    })

# Contoh pemanggilan:
notify_telegram(f"🔔 Subscriber baru: {email}")
