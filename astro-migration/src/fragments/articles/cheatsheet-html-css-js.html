⚡ JavaScript Array Methods

const arr = [1, 2, 3, 4, 5];

arr.map(x => x * 2)           // [2, 4, 6, 8, 10]
arr.filter(x => x > 3)        // [4, 5]
arr.reduce((a, b) => a + b, 0) // 15
arr.find(x => x > 3)          // 4
arr.findIndex(x => x > 3)     // 3
arr.some(x => x > 4)          // true
arr.every(x => x > 0)         // true
arr.includes(3)               // true
arr.sort((a, b) => b - a)     // Descending
arr.flat()                     // Flatten nested

📱 Responsive Design (Media Queries)

/* Mobile First Approach */
.container {
  padding: 16px;
  font-size: 14px;
}

/* Tablet (768px+) */
@media (min-width: 768px) {
  .container {
    padding: 24px;
    font-size: 16px;
    max-width: 720px;
    margin: 0 auto;
  }
  .sidebar { display: block; width: 250px; }
}

/* Desktop (1024px+) */
@media (min-width: 1024px) {
  .container { max-width: 960px; }
  .grid { grid-template-columns: repeat(3, 1fr); }
}

/* Print */
@media print {
  .no-print { display: none; }
  body { font-size: 12pt; color: #000; }
}

el.addEventListener("click", (e) => {

// Event delegation (efficient for many items)
document.querySelector(".list").addEventListener("click", (e) => {
  if (e.target.matches(".list-item")) {
    console.log("Item clicked:", e.target.dataset.id);
  }
});

⏳ Async/Await & Error Handling

// Async function
async function fetchUser(id) {
  try {
    const res = await fetch(`/api/users/${id}`);
    if (!res.ok) throw new Error(`HTTP ${res.status}`);
    const user = await res.json();
    return user;
  } catch (err) {
    console.error("Gagal fetch user:", err.message);
    return null;
  }
}

// Parallel requests
async function fetchAll() {
  const [users, posts] = await Promise.all([
    fetch("/api/users").then(r => r.json()),
    fetch("/api/posts").then(r => r.json())
  ]);
  return { users, posts };
}

// Loading state pattern
async function loadData() {
  const btn = document.querySelector("#loadBtn");
  btn.disabled = true;
  btn.textContent = "Loading...";
  try {
    const data = await fetchUser(1);
    renderUser(data);
  } finally {
    btn.disabled = false;
    btn.textContent = "Load";
  }
}

💡 Tips & Best Practices

📋 Semantic HTML: Selalu gunakan semantic tags (<header>, <nav>, <main>, <article>, <footer>) bukan <div> semata. Ini meningkatkan aksesibilitas untuk screen reader, membantu SEO karena search engine lebih mudah memahami struktur halaman, dan membuat kode lebih mudah dibaca developer lain.

📦 Flexbox vs Grid: Gunakan Flexbox untuk layout satu dimensi (baris ATAU kolom) seperti navbar, card row, atau centering. Gunakan Grid untuk layout dua dimensi (baris DAN kolom) seperti page layout, dashboard, atau image gallery. Keduanya bisa digabung — Grid untuk page structure, Flexbox untuk komponen di dalamnya.

⚡ JavaScript Performance: Hindari manipulasi DOM berulang — batch perubahan sekaligus. Gunakan DocumentFragment untuk menambah banyak elemen. Gunakan requestAnimationFrame() untuk animasi, bukan setInterval(). Debounce event handler yang sering terpicu (scroll, resize, input).

🎨 CSS Specificity: Hindari !important — ini tanda specificity yang buruk. Hindari juga inline style. Gunakan class selector dan BEM naming convention untuk menghindari konflik. Urutan specificity: element < class < ID < inline < !important.

🔒 Security: Jangan gunakan innerHTML untuk menampilkan user input — gunakan textContent untuk mencegah XSS. Selalu validate input di sisi server, bukan hanya client-side. Gunakan Content-Security-Policy header.

📱 Mobile First: Selalu tulis CSS mobile-first: style dasar untuk mobile, lalu override dengan @media (min-width: ...) untuk layar lebih besar. Ini menghasilkan CSS yang lebih ringan dan pengalaman mobile yang lebih baik.
