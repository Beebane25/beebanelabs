Cheatsheet Networking & MikroTik: Command Line, Subnetting, dan RouterOS

Referensi cepat OSI model, subnetting, MikroTik CLI, firewall, DHCP, dan VPN configuration.

📅 3 Juli 2026 📖 10 menit baca Pemula

Tim BeebaneLabs Penulis & Kontributor Teknologi

Networking adalah tulang punggung setiap infrastruktur IT, dan MikroTik RouterOS adalah salah satu platform router paling populer di Indonesia berkat harga terjangkau dan fitur lengkap. Cheatsheet ini mencakup konsep fundamental jaringan seperti OSI model dan subnetting, dilengkapi dengan command-line MikroTik untuk konfigurasi interface, DHCP, firewall, VLAN, VPN, bandwidth management, dan troubleshooting. Baik Anda mempersiapkan sertifikasi jaringan atau mengelola infrastruktur kantor, halaman ini adalah referensi cepat yang bisa Anda buka kapan saja.

🔧 MikroTik CLI

# Interface
/interface print
/interface ethernet print
/interface enable ether1
/interface disable ether2

# IP Address
/ip address add address=192.168.1.1/24 interface=ether1
/ip address print

# DHCP
/ip pool add name=dhcp_pool ranges=192.168.1.10-192.168.1.100
/ip dhcp-server add name=dhcp1 interface=ether1 address-pool=dhcp_pool
/ip dhcp-server network add address=192.168.1.0/24 gateway=192.168.1.1

# DNS
/ip dns set servers=8.8.8.8,8.8.4.4
/ip dns set allow-remote-requests=yes

# NAT (masquerade)
/ip firewall nat add chain=srcnat out-interface=ether1 action=masquerade

# Static route
/ip route add dst-address=0.0.0.0/0 gateway=10.0.0.1

🛡️ MikroTik Firewall

# Filter rules
/ip firewall filter add chain=input protocol=icmp action=accept
/ip firewall filter add chain=input connection-state=established action=accept
/ip firewall filter add chain=input connection-state=related action=accept
/ip firewall filter add chain=input protocol=tcp dst-port=8291 action=accept comment="Winbox"
/ip firewall filter add chain=input protocol=tcp dst-port=22 action=accept comment="SSH"
/ip firewall filter add chain=input action=drop comment="Drop all"

# Anti brute-force
/ip firewall filter add chain=input protocol=tcp dst-port=22 \
  connection-state=new src-address-list=ssh_blacklist action=drop
/ip firewall filter add chain=input protocol=tcp dst-port=22 \
  connection-state=new action=add-src-to-address-list \
  address-list=ssh_blacklist address-list-timeout=1d

📡 VLAN

# Create VLAN
/interface vlan add name=vlan10 vlan-id=10 interface=ether1
/interface vlan add name=vlan20 vlan-id=20 interface=ether1

# Assign IP
/ip address add address=192.168.10.1/24 interface=vlan10
/ip address add address=192.168.20.1/24 interface=vlan20

# Bridge VLAN
/interface bridge add name=bridge1
/interface bridge port add bridge=bridge1 interface=ether2
/interface bridge vlan add bridge=bridge1 vlan-ids=10 tagged=ether1 untagged=ether2

📡 VPN Configuration

# PPTP Server
/interface pptp-server server set enabled=yes
/ppp secret add name=user1 password=pass1 service=pptp local-address=10.0.0.1 remote-address=10.0.0.100

# L2TP Server
/interface l2tp-server server set enabled=yes default-profile=default-encryption
/ppp secret add name=user2 password=pass2 service=l2tp

# WireGuard
/interface wireguard add name=wg1 listen-port=51820
/ip address add address=10.10.10.1/24 interface=wg1
/interface wireguard peers add interface=wg1 public-key="CLIENT_PUB_KEY" allowed-address=10.10.10.2/32

🔍 Troubleshooting

# Ping & traceroute
/ping 8.8.8.8 count=5
/tool traceroute 8.8.8.8

# Connection tracking
/ip firewall connection print
/ip firewall connection tracking print

# Interface stats
/interface monitor-traffic ether1
/tool bandwidth-test address=192.168.1.1

# Logs
/log print where topics~"firewall"
/log print where topics~"dhcp"

# DNS test
/tool dns lookup=google.com

📊 Bandwidth Management

# Simple Queue
/queue simple add name="User1" target=192.168.1.10/32 max-limit=10M/10M
/queue simple add name="User2" target=192.168.1.11/32 max-limit=5M/5M

# Queue Tree (parent-child)
/queue tree add name="Download" parent=global
/queue tree add name="User1-DL" parent=Download limit-at=5M max-limit=10M

# PCQ (Per Connection Queue)
/queue type add name="pcq-download" kind=pcq pcq-classifier=dst-address
/queue type add name="pcq-upload" kind=pcq pcq-classifier=src-address

💡 Tips & Best Practices

  • Backup konfigurasi sebelum perubahan — jalankan /system backup save name=pre-change dan export file sebelum edit firewall/routing. Konfigurasi salah = bisa lockout diri sendiri.
  • Gunakan comment pada setiap rule — tambahkan parameter comment="Deskripsi" pada setiap firewall rule dan NAT. Tanpa comment, debug 50+ rules adalah mimpi buruk.
  • Firewall: urutan matters — rule di atas dieksekusi duluan. Taruh DROP/ACCEPT spesifik di atas, generic rule di bawah.
  • Aktikasikan Winbox + SSH — jangan hanya mengandalkan satu metode akses. Jika SSH terkunci, masih bisa via Winbox (atau sebaliknya).
  • Gunakan address-list untuk grouping IP — lebih efisien daripada membuat rule terpisah untuk setiap IP. Contoh: address-list "kantor", "whitelist", "blacklist".
  • Monitor resource usage — jalankan /system resource print secara berkala. MikroTik entry-level punya RAM terbatas, jangan overload dengan rule terlalu banyak.
  • Disable unused services — matikan service yang tidak dipakai (/ip service disable telnet,ftp,api) untuk mengurangi attack surface.
  • Update RouterOS secara berkala — cek changelog di mikrotik.com sebelum update. Test di perangkat non-production dulu jika memungkinkan.
