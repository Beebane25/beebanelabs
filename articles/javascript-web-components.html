1. Pengenalan Web Components

Web Components adalah sekumpulan API web standar yang memungkinkan Anda membuat elemen HTML custom yang reusable, terenkapsulasi, dan dapat digunakan di aplikasi web mana pun — tanpa terikat pada framework tertentu seperti React, Vue, atau Angular.

Teknologi ini didukung langsung oleh browser, sehingga tidak memerlukan library tambahan. Web Components terdiri dari tiga teknologi utama: Custom Elements, Shadow DOM, dan HTML Templates.

Mengapa Menggunakan Web Components?

Keunggulan Penjelasan
Native Browser APITidak perlu library atau bundler — didukung langsung oleh semua browser modern
Framework AgnosticBisa digunakan di React, Vue, Angular, Svelte, atau bahkan HTML murni
EnkapsulasiShadow DOM memastikan style dan DOM terisolasi dari halaman utama
ReusableSatu komponen bisa dipakai di berbagai proyek tanpa modifikasi
Standar WebDidukung oleh W3C dan terus berkembang dengan spesifikasi baru
Kompabilitas Jangka PanjangBagian dari standar web — tidak akan di-deprecated seperti framework tertentu

💡 Tips

Web Components sangat cocok untuk membuat sistem design library yang bisa dipakai lintas framework. Perusahaan seperti SAP (UI5 Web Components), Adobe (Spectrum), dan Ionic (Stencil) menggunakan Web Components sebagai dasar library UI mereka.

2. Custom Elements

Custom Elements memungkinkan Anda mendefinisikan elemen HTML baru dengan JavaScript. Elemen ini bisa memiliki perilaku sendiri, template, dan lifecycle callbacks yang akan dipanggil secara otomatis oleh browser.

Membuat Custom Element Pertama

JavaScript — Custom Element Dasar 
// Definisikan class yang extends HTMLElement
class SalamWidget extends HTMLElement {
  constructor() {
    super();
    // Jangan akses attributes atau children di sini
    this.attachShadow({ mode: 'open' });
    this.shadowRoot.innerHTML = `
      <style>
        .salam {
          padding: 16px;
          background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
          color: white;
          border-radius: 8px;
          font-family: sans-serif;
          text-align: center;
        }
      </style>
      <div class="salam">
        <h2>👋 Halo dari Web Component!</h2>
        <p>Ini adalah custom element pertama Anda.</p>
      </div>
    `;
  }
}

// Daftarkan custom element dengan nama (harus ada tanda hubung)
customElements.define('salam-widget', SalamWidget);

// Gunakan di HTML:
// <salam-widget></salam-widget>

3. Shadow DOM

Shadow DOM adalah mekanisme enkapsulasi yang memungkinkan Anda menyembunyikan struktur DOM internal dan style sebuah komponen dari halaman utama. Ini mencegah konflik CSS dan memastikan komponen berperilaku konsisten di mana pun dipasang.

Konsep Dasar Shadow DOM

JavaScript — Shadow DOM Dasar 
class KartuInfo extends HTMLElement {
  constructor() {
    super();

    // Buat Shadow Root
    // mode: 'open' → bisa diakses dari luar via el.shadowRoot
    // mode: 'closed' → tidak bisa diakses dari luar (lebih aman)
    const shadow = this.attachShadow({ mode: 'open' });

    // Semua yang ada di shadow root ter-enkapsulasi
    shadow.innerHTML = `
      <style>
        /* Style ini TIDAK akan mempengaruhi elemen lain */
        /* dan style dari luar TIDAK akan masuk ke sini */
        .kartu {
          border: 2px solid #3b82f6;
          border-radius: 12px;
          padding: 20px;
          margin: 10px;
          background: #1e293b;
          color: #e2e8f0;
          font-family: sans-serif;
          box-shadow: 0 4px 6px rgba(0, 0, 0, 0.3);
        }

        .kartu h3 {
          margin: 0 0 8px 0;
          color: #60a5fa;
        }

        .kartu p {
          margin: 0;
          line-height: 1.6;
        }
      </style>
      <div class="kartu">
        <h3>Judul Kartu</h3>
        <p>Konten yang ter-enkapsulasi di dalam Shadow DOM.</p>
      </div>
    `;
  }
}

customElements.define('kartu-info', KartuInfo);

// <kartu-info></kartu-info>

Open vs Closed Shadow DOM

Mode Akses dari Luar Penggunaan

JavaScript — Open vs Closed 
// OPEN — bisa diakses dari luar
class OpenComponent extends HTMLElement {
  constructor() {
    super();
    this.attachShadow({ mode: 'open' });
    this.shadowRoot.innerHTML = '<p>Open shadow DOM</p>';
  }
}

const open = document.createElement('open-component');
document.body.appendChild(open);
console.log(open.shadowRoot);  // #shadow-root (open) ✅

// CLOSED — tidak bisa diakses dari luar
class ClosedComponent extends HTMLElement {
  constructor() {
    super();
    this.attachShadow({ mode: 'closed' });
    // Simpan referensi internal jika perlu
    this._shadow = this.attachShadow({ mode: 'closed' });
    this._shadow.innerHTML = '<p>Closed shadow DOM</p>';
  }
}

const closed = document.createElement('closed-component');
document.body.appendChild(closed);
console.log(closed.shadowRoot);  // null ❌

Event Handling di Shadow DOM

JavaScript — Shadow DOM Event 
class EventDemo extends HTMLElement {
  constructor() {
    super();
    this.attachShadow({ mode: 'open' });
    this.shadowRoot.innerHTML = `
      <button id="tombol">Klik Saya</button>
      <p id="output">Menunggu klik...</p>
    `;
  }

  connectedCallback() {
    const tombol = this.shadowRoot.getElementById('tombol');
    const output = this.shadowRoot.getElementById('output');

    tombol.addEventListener('click', (e) => {
      output.textContent = 'Tombol diklik pada: ' + new Date().toLocaleTimeString();

      // Dispatch custom event ke light DOM
      this.dispatchEvent(new CustomEvent('tombol-diklik', {
        detail: { waktu: Date.now() },
        bubbles: true,    // Event naik ke parent
        composed: true,   // Event bisa melewati shadow boundary
      }));
    });
  }
}

customElements.define('event-demo', EventDemo);

// Mendengarkan event dari luar
document.querySelector('event-demo')
  .addEventListener('tombol-diklik', (e) => {
    console.log('Event diterima:', e.detail);

4. HTML Templates & Slots

HTML Templates (<template>) adalah elemen yang berisi konten yang tidak langsung dirender oleh browser. Konten di dalam <template> baru aktif saat Anda mengklonnya dan memasukkannya ke DOM. Slots memungkinkan konten dari luar (light DOM) di-inject ke dalam template.

Menggunakan <template>

HTML — Template Element

    .card {
      border: 1px solid #3b82f6;
      border-radius: 8px;
      padding: 16px;
      margin: 8px;
      display: flex;
      gap: 12px;
      align-items: center;
      background: #1e293b;
    }
    .avatar {
      width: 48px;

      background: #3b82f6;
      display: flex;
      align-items: center;

      font-size: 24px;
    }
    .info h3 { margin: 0; color: #60a5fa; }
    .info p { margin: 4px 0 0; color: #94a3b8; font-size: 14px; }
  </style>
  <div class="card">
    <div class="avatar">👤</div>

JavaScript — Menggunakan Template 
class UserCard extends HTMLElement {
  constructor() {
    super();
    this.attachShadow({ mode: 'open' });

    // Ambil template dari DOM
    const template = document.getElementById('user-card-template');
    const templateContent = template.content;

    // Klon template dan masukkan ke shadow root
    this.shadowRoot.appendChild(templateContent.cloneNode(true));
  }
}

Slot Change Event

JavaScript — Slot Change Detection 
class DynamicPanel extends HTMLElement {
  constructor() {
    super();
    this.attachShadow({ mode: 'open' });
    this.shadowRoot.innerHTML = `
      <div class="panel">
        <slot name="content"></slot>
      </div>
    `;
  }

  connectedCallback() {
    const slot = this.shadowRoot.querySelector('slot[name="content"]');

    // Event 'slotchange' fires saat konten slot berubah
    slot.addEventListener('slotchange', (e) => {
      const nodes = slot.assignedNodes();
      console.log(`Slot content berubah: ${nodes.length} node`);
      console.log('Nodes:', nodes.map(n => n.textContent));

      // Update UI berdasarkan konten
      this.updateBadge(nodes.length);
    });
  }

  updateBadge(count) {
    let badge = this.shadowRoot.querySelector('.badge');
    if (!badge) {
      badge = document.createElement('span');
      badge.className = 'badge';
      badge.style.cssText = `
        background: #ef4444; color: white; padding: 2px 8px;
        border-radius: 12px; font-size: 12px; margin-left: 8px;
      `;
      this.shadowRoot.querySelector('.panel').prepend(badge);
    }
    badge.textContent = count;
  }
}

customElements.define('dynamic-panel', DynamicPanel);

5. Attributes & Properties

Custom Elements mendukung attributes (HTML) dan properties (JavaScript). Yang terpenting adalah menghubungkan keduanya agar komponen tetap sinkron.

JavaScript — Attributes & Properties 
class ProgressBar extends HTMLElement {
  // Daftar attribute yang diamati perubahannya
  static get observedAttributes() {
    return ['value', 'max', 'label', 'color'];
  }

  constructor() {
    super();
    this.attachShadow({ mode: 'open' });
    this._value = 0;
    this._max = 100;
    this._label = 'Progress';
    this._color = '#3b82f6';
    this.render();
  }

  // Property getters/setters — hubungkan ke attributes
  get value() { return this._value; }
  set value(val) {
    this._value = Math.min(Math.max(Number(val), 0), this._max);
    this.setAttribute('value', this._value);
    this.render();
  }

  get max() { return this._max; }
  set max(val) {
    this._max = Number(val) || 100;
    this.setAttribute('max', this._max);
    this.render();
  }

  get label() { return this._label; }
  set label(val) {
    this._label = val;
    this.setAttribute('label', val);
    this.render();
  }

  // Callback saat attribute berubah dari HTML
  attributeChangedCallback(name, oldVal, newVal) {
    if (oldVal === newVal) return;

    switch (name) {
      case 'value':
        this._value = Math.min(Math.max(Number(newVal), 0), this._max);
        break;
      case 'max':
        this._max = Number(newVal) || 100;
        break;
      case 'label':
        this._label = newVal;
        break;
      case 'color':
        this._color = newVal;
        break;
    }
    this.render();
  }

  render() {
    const percent = Math.round((this._value / this._max) * 100);
    this.shadowRoot.innerHTML = `
      <style>
        .progress-container {
          font-family: sans-serif;
          margin: 8px 0;
        }
        .progress-label {
          display: flex;
          justify-content: space-between;
          margin-bottom: 4px;
          color: #e2e8f0;
          font-size: 14px;
        }
        .progress-bar {
          height: 12px;
          background: #334155;
          border-radius: 6px;
          overflow: hidden;
        }
        .progress-fill {
          height: 100%;
          width: ${percent}%;
          background: ${this._color};
          border-radius: 6px;
          transition: width 0.3s ease;
        }
      </style>
      <div class="progress-container">
        <div class="progress-label">
          <span>${this._label}</span>
          <span>${percent}%</span>
        </div>
        <div class="progress-bar">
          <div class="progress-fill"></div>
        </div>
      </div>
    `;
  }
}

customElements.define('progress-bar', ProgressBar);

6. Custom Events

Custom Events memungkinkan komponen Web Components berkomunikasi dengan komponen lain dan kode di luar secara terstruktur. Ini adalah pola yang sama dengan yang digunakan oleh elemen HTML native (seperti click, input, change).

JavaScript — Custom Events 
class RatingBintang extends HTMLElement {
  static get observedAttributes() { return ['max', 'value']; }

  constructor() {
    super();
    this.attachShadow({ mode: 'open' });
    this._max = 5;
    this._value = 0;
    this.render();
  }

  attributeChangedCallback(name, old, val) {
    if (name === 'max') this._max = Number(val);
    if (name === 'value') this._value = Number(val);
    this.render();
  }

  render() {
    const bintang = [];
    for (let i = 1; i <= this._max; i++) {
      const filled = i <= this._value ? '★' : '☆';
      bintang.push(
        `<span class="bintang ${i <= this._value ? 'active' : ''}"
              data-nilai="${i}">${filled}</span>`
      );
    }

    this.shadowRoot.innerHTML = `
      <style>
        .rating { display: flex; gap: 4px; cursor: pointer; font-size: 24px; }
        .bintang { color: #475569; transition: color 0.2s, transform 0.2s; }
        .bintang.active { color: #fbbf24; }
        .bintang:hover { transform: scale(1.2); }
      </style>
      <div class="rating">${bintang.join('')}</div>
    `;

    // Event delegation
    this.shadowRoot.querySelectorAll('.bintang').forEach(el => {
      el.addEventListener('click', () => {
        const nilai = Number(el.dataset.nilai);
        this._value = nilai;
        this.setAttribute('value', nilai);
        this.render();

        // Dispatch custom event!
        this.dispatchEvent(new CustomEvent('rating-change', {
          detail: {
            value: nilai,
            max: this._max,
            percentage: Math.round((nilai / this._max) * 100),
          },
          bubbles: true,
          composed: true,
        }));
      });
    });
  }
}

customElements.define('rating-bintang', RatingBintang);

7. Lifecycle Callbacks

Custom Elements memiliki serangkaian lifecycle callbacks yang dipanggil secara otomatis oleh browser pada momen-momen penting dalam kehidupan elemen.

Callback Dipanggil Saat Gunakan Untuk
constructor()Elemen dibuat/upgradedInisialisasi state, buat shadow DOM
connectedCallback()Elemen ditambahkan ke DOMSetup event listener, fetch data, render
disconnectedCallback()Elemen dihapus dari DOMCleanup: hapus listener, cancel timer
attributeChangedCallback()Attribute diamati berubahRe-render, update state
adoptedCallback()Elemen dipindah ke dokumen baruLangka: adaptasi ke document baru
JavaScript — Lifecycle Lengkap 
class ClockWidget extends HTMLElement {
  static get observedAttributes() { return ['timezone']; }

  constructor() {
    super();
    console.log('1. constructor() — elemen dibuat');
    this.attachShadow({ mode: 'open' });
    this._timezone = 'Asia/Jakarta';
    this._interval = null;
  }

  connectedCallback() {
    console.log('2. connectedCallback() — elemen masuk DOM');
    this.render();
    this.startClock();
    this.shadowRoot.querySelector('select')
      ?.addEventListener('change', this._onTimezoneChange.bind(this));
  }

  disconnectedCallback() {
    console.log('3. disconnectedCallback() — elemen keluar DOM');
    this.stopClock();
  }

  attributeChangedCallback(name, oldVal, newVal) {
    console.log(`4. attributeChangedCallback(${name}, ${oldVal}, ${newVal})`);
    if (name === 'timezone' && oldVal !== newVal) {
      this._timezone = newVal;
      this.render();
    }
  }

  adoptedCallback() {
    console.log('5. adoptedCallback() — elemen dipindah dokumen');
  }

  _onTimezoneChange(e) {
    this._timezone = e.target.value;
    this.setAttribute('timezone', this._timezone);
  }

  startClock() {
    this._interval = setInterval(() => this.render(), 1000);
  }

  stopClock() {
    if (this._interval) {
      clearInterval(this._interval);
      this._interval = null;
    }
  }

  render() {
    const now = new Date().toLocaleTimeString('id-ID', {
      timeZone: this._timezone,
      hour: '2-digit',
      minute: '2-digit',
      second: '2-digit',
    });

    this.shadowRoot.innerHTML = `
      <style>
        .clock {
          text-align: center; padding: 20px;
          background: #0f172a; border-radius: 12px;
          border: 1px solid #334155; font-family: monospace;
        }
        .time { font-size: 48px; color: #22d3ee; }
        .zone { color: #94a3b8; margin-top: 8px; }
        select {
          margin-top: 12px; padding: 8px 12px;
          background: #1e293b; color: #e2e8f0;
          border: 1px solid #475569; border-radius: 6px;
        }
      </style>
      <div class="clock">
        <div class="time">${now}</div>
        <div class="zone">${this._timezone}</div>
        <select>
          <option value="Asia/Jakarta" ${this._timezone === 'Asia/Jakarta' ? 'selected' : ''}>WIB</option>
          <option value="Asia/Makassar" ${this._timezone === 'Asia/Makassar' ? 'selected' : ''}>WITA</option>
          <option value="Asia/Jayapura" ${this._timezone === 'Asia/Jayapura' ? 'selected' : ''}>WIT</option>
          <option value="Europe/London" ${this._timezone === 'Europe/London' ? 'selected' : ''}>London</option>
        </select>
      </div>
    `;
  }
}

customElements.define('clock-widget', ClockWidget);

9. Praktik: Membuat Komponen Lengkap

Mari kita gabungkan semua yang telah dipelajari untuk membuat Accordion Component — komponen expandable/collapsible yang lengkap dengan animations, accessibility, dan styling.

JavaScript — Accordion Component (Lengkap) 
class AccordionItem extends HTMLElement {
  static get observedAttributes() { return ['open', 'disabled']; }

  constructor() {
    super();
    this.attachShadow({ mode: 'open' });
    this._open = false;
    this._disabled = false;
  }

  connectedCallback() {
    this._open = this.hasAttribute('open');
    this._disabled = this.hasAttribute('disabled');
    this.render();
    this._setupEvents();
  }

  attributeChangedCallback(name, old, val) {
    if (name === 'open') {
      this._open = val !== null;
      this._updatePanel();
    }
    if (name === 'disabled') {
      this._disabled = val !== null;
      this._updateDisabled();
    }
  }

  _setupEvents() {
    const header = this.shadowRoot.querySelector('.accordion-header');
    header.addEventListener('click', () => {
      if (this._disabled) return;
      this._open = !this._open;
      if (this._open) {
        this.setAttribute('open', '');
      } else {
        this.removeAttribute('open');
      }
      this.dispatchEvent(new CustomEvent('accordion-toggle', {
        detail: { open: this._open },
        bubbles: true,
        composed: true,
      }));
    });
  }

  _updatePanel() {
    const panel = this.shadowRoot.querySelector('.accordion-panel');
    const icon = this.shadowRoot.querySelector('.accordion-icon');
    if (panel) {
      panel.style.maxHeight = this._open ? panel.scrollHeight + 'px' : '0';
      panel.classList.toggle('open', this._open);
    }
    if (icon) {
      icon.style.transform = this._open ? 'rotate(180deg)' : 'rotate(0)';
    }
  }

  _updateDisabled() {
    const header = this.shadowRoot.querySelector('.accordion-header');
    if (header) {
      header.classList.toggle('disabled', this._disabled);
    }
  }

  render() {
    this.shadowRoot.innerHTML = `
      <style>
        :host {
          display: block;
          border: 1px solid var(--accordion-border, #334155);
          border-radius: 8px;
          margin-bottom: 8px;
          overflow: hidden;
          background: var(--accordion-bg, #0f172a);
        }
        .accordion-header {
          display: flex;
          justify-content: space-between;
          align-items: center;
          padding: 16px;
          cursor: pointer;
          user-select: none;
          color: var(--accordion-header-color, #f1f5f9);
          font-family: system-ui, sans-serif;
          font-weight: 600;
          transition: background 0.2s;
        }
        .accordion-header:hover {
          background: var(--accordion-hover, #1e293b);
        }
        .accordion-header.disabled {
          opacity: 0.5;
          cursor: not-allowed;
        }
        .accordion-icon {
          transition: transform 0.3s ease;
          font-size: 12px;
          color: #64748b;
        }
        .accordion-panel {
          max-height: 0;
          overflow: hidden;
          transition: max-height 0.3s ease;
          padding: 0 16px;
          color: var(--accordion-body-color, #94a3b8);
          font-family: system-ui, sans-serif;
          line-height: 1.6;
        }
        .accordion-panel.open {
          padding-bottom: 16px;
        }
      </style>
      <div class="accordion-header" role="button" tabindex="0"
           aria-expanded="${this._open}">
        <slot name="header">Item</slot>
        <span class="accordion-icon">▼</span>
      </div>
      <div class="accordion-panel" role="region">
        <slot></slot>
      </div>
    `;

    this._setupEvents();
    if (this._open) this._updatePanel();
    if (this._disabled) this._updateDisabled();
  }
}

customElements.define('accordion-item', AccordionItem);

import React, { useRef, useEffect } from 'react';

// Web Component di React perlu perhatian khusus
function App() {
  const ratingRef = useRef(null);

  useEffect(() => {
    // Custom events harus di-bind manual
    const el = ratingRef.current;
    const handler = (e) => {
      console.log('Rating:', e.detail.value);
    };
    el.addEventListener('rating-change', handler);
    return () => el.removeEventListener('rating-change', handler);
  }, []);

  return (
    <div>
      {/* Attributes bekerja */}
      <rating-bintang ref={ratingRef} max="5" value="3" />

      {/* Properties harus di-set via ref */}
      {/* Bukan:  */}
    </div>
  );
}
