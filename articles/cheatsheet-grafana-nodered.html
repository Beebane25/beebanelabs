Cheatsheet Grafana & Node-RED: PromQL, Dashboard, dan Flow Automation

Referensi cepat PromQL, Grafana dashboard, Node-RED flow, dan MQTT integration.

📅 3 Juli 2026 📖 10 menit baca Pemula

📊 PromQL Quick Reference

# Instant vector
up                              # Status semua target
http_requests_total             # Total HTTP requests

# Rate & increase
rate(http_requests_total[5m])   # Request per detik (5m window)
increase(http_requests_total[1h])  # Penambahan dalam 1 jam

# Aggregation
sum(rate(http_requests_total[5m])) by (method)
avg(node_cpu_seconds_total)
max(node_memory_MemTotal_bytes)
count(up == 1)

# Histogram
histogram_quantile(0.95, rate(http_duration_seconds_bucket[5m]))
histogram_quantile(0.99, sum(rate(http_duration_seconds_bucket[5m])) by (le))

📈 Grafana Variables

# Query variable
label_values(up, instance)          # Semua instance
label_values(http_requests_total{job="api"}, method)  # Methods

# Interval variable
$__interval                         # Auto interval
$__rate_interval                    # Rate interval

# Panel query dengan variable
rate(http_requests_total{instance="$instance"}[$__interval])

🔴 Node-RED Nodes

// MQTT Subscribe node
// Topic: sensor/temperature
// Output: msg.payload = data

// Function node
msg.payload = {
  temperature: parseFloat(msg.payload),
  timestamp: new Date().toISOString(),
  alert: msg.payload > 30 ? "HIGH" : "NORMAL"
};
return msg;

// HTTP Request node
msg.method = "POST";
msg.url = "https://api.example.com/data";
msg.headers = {"Content-Type": "application/json"};
return msg;

📋 Alert Rules (Grafana)

# Alert rule YAML
groups:
  - name: example
    rules:
      - alert: HighCPU
        expr: 100 - (avg by(instance) (rate(node_cpu_seconds_total{mode="idle"}[5m])) * 100) > 80
        for: 5m
        labels:
          severity: warning
        annotations:
          summary: "High CPU on {{ $labels.instance }}"
          description: "CPU usage is {{ $value }}%"

      - alert: ServiceDown
        expr: up == 0
        for: 1m
        labels:
          severity: critical
