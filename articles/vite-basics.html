1. Pengenalan Vite

Vite (bahasa Prancis untuk "cepat", dibaca /vit/) adalah build tool generasi baru yang dikembangkan oleh Evan You (pencipta Vue.js). Vite dirancang untuk mengatasi masalah performa yang dihadapi oleh bundler tradisional seperti Webpack saat mengembangkan proyek web modern.

Rahasia kecepatan Vite terletak pada dua hal: pertama, ia menggunakan native ES Modules untuk development server (tidak perlu bundle), dan kedua, ia menggunakan esbuild (ditulis dalam Go) untuk dependency pre-bundling yang 10-100x lebih cepat dari bundler JavaScript tradisional.

Mengapa Vite Sangat Cepat?

Aspek Webpack (Lama) Vite (Modern)
Dev Server Start🟡 5-30 detik (bundle semua)🟢 ~300ms (on-demand)
HMR🟡 1-5 detik (rebuild affected)🟢 ~50ms (instant)
Pre-bundlingJavaScript (slow)esbuild / Go (10-100x faster)
Module SystemCommonJS → BundleNative ESM → On-demand
ProductionWebpackRollup (battle-tested)
Konfigurasi🟡 Kompleks🟢 Minimal, sensible defaults

Siapa yang Menggunakan Vite?

💡 Ekosistem Vite

Vite digunakan oleh hampir semua framework modern: Vue.js (default), React, Svelte, Astro (built on Vite), Solid.js, Lit, Qwik, Nuxt 3, SvelteKit, dan banyak lagi. Meta-framework seperti Nuxt, SvelteKit, dan Astro semuanya dibangun di atas Vite.

3. Konfigurasi Dasar

Vite dikonfigurasi melalui file vite.config.js (atau .ts) di root proyek. Konfigurasi sangat minimal dibanding Webpack.

JavaScript — vite.config.js (Lengkap) 
import { defineConfig } from 'vite';
import react from '@vitejs/plugin-react';
import path from 'path';

// https://vitejs.dev/config/
export default defineConfig({
  // Plugins — fitur tambahan
  plugins: [
    react(),
  ],

  // Path aliases — import lebih bersih
  resolve: {
    alias: {
      '@': path.resolve(__dirname, './src'),
      '@components': path.resolve(__dirname, './src/components'),
      '@utils': path.resolve(__dirname, './src/utils'),
      '@assets': path.resolve(__dirname, './src/assets'),
    },
  },

  // Development server options
  server: {
    port: 3000,           // Port dev server
    open: true,           // Auto-open browser
    host: true,           // Expose ke network (0.0.0.0)
    strictPort: true,     // Error jika port sudah dipakai
    https: false,         // Aktifkan HTTPS

    // Proxy — redirect API calls ke backend
    proxy: {
      '/api': {
        target: 'http://localhost:8080',
        changeOrigin: true,
        rewrite: (path) => path.replace(/^\/api/, ''),
      },
    },
  },

  // Build options
  build: {
    outDir: 'dist',            // Output directory
    assetsDir: 'assets',       // Subdirectory untuk assets
    sourcemap: false,          // Source maps di production
    minify: 'esbuild',         // Minifier: 'esbuild' | 'terser'
    target: 'es2020',          // Target browser

    // Rollup options (Vite uses Rollup for production build)
    rollupOptions: {
      output: {
        // Manual chunk splitting
        manualChunks: {
          vendor: ['react', 'react-dom'],
          router: ['react-router-dom'],
        },
      },
    },

    // Asset size warning limit
    chunkSizeWarningLimit: 500,
  },

  // CSS options
  css: {
    // CSS Modules
    modules: {
      localsConvention: 'camelCase',
    },
    // Preprocessor options (Sass, Less, Stylus)
    preprocessorOptions: {
      scss: {
        additionalData: `@import "@/styles/variables.scss";`,
      },
    },
    // PostCSS options
    postcss: {
      plugins: [],
    },
  },

  // Optimization
  optimizeDeps: {
    include: ['react', 'react-dom'],  // Pre-bundle dependencies
    exclude: ['my-local-package'],    // Skip pre-bundling
  },
});
💡 Tips

Gunakan defineConfig() untuk mendapatkan autocompletion dan type checking. File konfigurasi mendukung vite.config.ts, vite.config.mjs, dan vite.config.cjs.

4. Development Server

Vite development server menggunakan native ESM — saat browser meminta sebuah modul, Vite mentransformasi dan menyajikannya secara on-demand. Ini berarti server start hampir instan, terlepas dari ukuran proyek.

Bash — Perintah Dev Server 
# Jalankan dev server
npm run dev

# Atau langsung
npx vite

# Dengan opsi spesifik
npx vite --port 3000
npx vite --host 0.0.0.0     # Expose ke network
npx vite --open              # Auto-open browser
npx vite --https             # Aktifkan HTTPS
npx vite --mode production   # Load .env.production

# Shortcut dalam package.json
{
  "scripts": {
    "dev": "vite",
    "dev:network": "vite --host",
    "dev:https": "vite --https",
    "preview": "vite preview",
    "build": "vite build",
    "build:analyze": "ANALYZE=true vite build"
  }
}

API Proxy

JavaScript — Server Proxy Configuration 
// vite.config.js
export default defineConfig({
  server: {
    proxy: {
      // Simple proxy
      '/api': 'http://localhost:8080',

      // Advanced proxy
      '/api/v2': {
        target: 'http://localhost:8080',
        changeOrigin: true,
        secure: false,
        rewrite: (path) => path.replace(/^\/api\/v2/, '/v2'),
        configure: (proxy, options) => {
          proxy.on('proxyReq', (proxyReq, req, res) => {
            console.log(`[Proxy] ${req.method} ${req.url} → ${options.target}${proxyReq.path}`);
          });
        },
      },

      // WebSocket proxy
      '/ws': {
        target: 'ws://localhost:8080',
        ws: true,
      },

      // Proxy ke multiple backends
      '/auth': 'http://localhost:3001',
      '/storage': 'http://localhost:3002',
    },
  },
});

// Di frontend, fetch('/api/users') akan di-proxy ke http://localhost:8080/users

5. Hot Module Replacement (HMR)

Hot Module Replacement (HMR) memungkinkan Anda mengubah kode dan melihat hasilnya di browser tanpa me-reload halaman penuh. Vite HMR sangat cepat karena hanya memproses modul yang berubah.

JavaScript — HMR API 
// HMR API tersedia di module.hot
// Biasanya framework plugin (React, Vue, Svelte) menangani ini otomatis

// Manual HMR handling (untuk vanilla JS)
if (import.meta.hot) {
  // Terima update untuk modul ini
  import.meta.hot.accept((newModule) => {
    console.log('Modul di-update!', newModule);
    // Jalankan kode untuk apply perubahan
  });

  // Terima update dari modul spesifik
  import.meta.hot.accept('./utils.js', (newUtils) => {
    // Apply update dari utils.js
    console.log('Utils di-update:', newUtils);
  });

  // Event: sebelum update
  import.meta.hot.on('vite:beforeUpdate', (payload) => {
    console.log('Akan update:', payload.updates);
  });

  // Event: setelah update
  import.meta.hot.on('vite:afterUpdate', (payload) => {
    console.log('Selesai update:', payload.updates);
  });

  // Dispose — cleanup sebelum modul di-replace
  import.meta.hot.dispose((data) => {
    // Simpan state yang perlu dipertahankan
    data.counter = currentCounter;
    // Cleanup: hapus interval, listener, dll.
    clearInterval(myInterval);
  });

  // Terima data dari dispose sebelumnya
  if (import.meta.hot.data.counter) {
    currentCounter = import.meta.hot.data.counter;
  }
}

6. Plugin System

Vite memiliki sistem plugin yang kompatibel dengan Rollup plugins dan ditambah dengan beberapa plugin khusus Vite. Plugin digunakan untuk menambah fitur seperti framework support, CSS processing, asset optimization, dan banyak lagi.

Plugin Populer

Bash — Instalasi Plugin Populer 
# Framework plugins
npm i -D @vitejs/plugin-react       # React + Fast Refresh
npm i -D @vitejs/plugin-vue         # Vue SFC
npm i -D @sveltejs/vite-plugin-svelte  # Svelte

# CSS
npm i -D @tailwindcss/vite          # Tailwind CSS v4
npm i -D vite-plugin-svgr           # SVG as React components
npm i -D vite-plugin-css-injected-by-js  # Inline CSS ke JS

# Utilities
npm i -D vite-plugin-pwa            # Progressive Web App
npm i -D vite-plugin-compression    # Gzip/Brotli compression
npm i -D vite-plugin-visualizer     # Bundle analyzer
npm i -D vite-plugin-mock-dev-server # Mock API
npm i -D unplugin-auto-import       # Auto import
npm i -D unplugin-icons             # Icon components

# Dev tools
npm i -D vite-plugin-checker        # TypeScript / ESLint checker
JavaScript — Konfigurasi dengan Plugin 
// vite.config.js
import { defineConfig } from 'vite';
import react from '@vitejs/plugin-react';
import { VitePWA } from 'vite-plugin-pwa';
import compression from 'vite-plugin-compression';
import { visualizer } from 'rollup-plugin-visualizer';
import AutoImport from 'unplugin-auto-import/vite';
import checker from 'vite-plugin-checker';

export default defineConfig({
  plugins: [
    // React with Fast Refresh
    react(),

    // Auto-import React hooks (tidak perlu import manual)
    AutoImport({
      imports: ['react'],
      dts: 'src/auto-imports.d.ts',
    }),

    // PWA support
    VitePWA({
      registerType: 'autoUpdate',
      includeAssets: ['favicon.svg', 'robots.txt'],
      manifest: {
        name: 'My App',
        short_name: 'App',
        theme_color: '#0f172a',
        icons: [
          { src: '/icon-192.png', sizes: '192x192', type: 'image/png' },
          { src: '/icon-512.png', sizes: '512x512', type: 'image/png' },
        ],
      },
    }),

    // Compress assets (gzip)
    compression({
      algorithm: 'gzip',
      ext: '.gz',
    }),

    // Brotli compression
    compression({
      algorithm: 'brotliCompress',
      ext: '.br',
    }),

    // TypeScript checker
    checker({
      typescript: true,
      eslint: { lintCommand: 'eslint src' },
    }),

    // Bundle analyzer (hanya saat ANALYZE=true)
    process.env.ANALYZE && visualizer({
      open: true,
      filename: 'bundle-analysis.html',
      gzipSize: true,
    }),
  ].filter(Boolean),
});

Membuat Plugin Sendiri

JavaScript — Custom Vite Plugin 
// vite-plugin-file-header.js
// Plugin sederhana: tambahkan komentar header ke semua file

export default function fileHeaderPlugin(options = {}) {
  const { banner = '/* Generated by Vite */' } = options;

  return {
    // Nama plugin (wajib)
    name: 'vite-plugin-file-header',

    // Hook: transform kode
    transform(code, id) {
      // Hanya proses file .js dan .jsx
      if (!id.match(/\.(js|jsx)$/)) return null;

      // Jangan proses node_modules
      if (id.includes('node_modules')) return null;

      // Tambahkan banner di awal file
      return {
        code: `${banner}\n${code}`,
        map: null, // Source map
      };
    },

    // Hook: saat server dimulai
    configureServer(server) {
      console.log('🚀 Dev server started!');
    },

    // Hook: saat build selesai
    closeBundle() {
      console.log('✅ Build selesai!');
    },
  };
}

// Plugin untuk logging transform
export function debugPlugin() {
  return {
    name: 'vite-plugin-debug',
    enforce: 'pre', // Jalankan sebelum plugin lain

    transform(code, id) {
      if (id.includes('src/')) {
        console.log(`[Transform] ${id} (${code.length} chars)`);
      }
      return null; // Tidak mengubah kode
    },
  };
}

7. Assets & Static Files

Vite membedakan antara static assets (di public/) dan imported assets (di src/). Keduanya memiliki perilaku berbeda.

Lokasi Perilaku Contoh
public/Di-serve apa adanya, tidak diproses bundlerfavicon, robots.txt, manifest.json
src/assets/Diproses bundler (hashed, optimized)Gambar, font, SVG yang diimport di JS/CSS
JavaScript — Menggunakan Assets 
// ═══ Public Assets — path absolut dari root ═══
// File: public/logo.png
// URL:  /logo.png
<img src="/logo.png" alt="Logo" />

// ═══ Imported Assets — diproses bundler ═══
// File: src/assets/hero.jpg

// Di JavaScript
import heroImage from './assets/hero.jpg';
// heroImage = '/assets/hero-abc123.jpg' (hashed URL)

document.getElementById('hero').src = heroImage;

// Di JSX
import heroImage from './assets/hero.jpg';
<img src={heroImage} alt="Hero" />

// Di CSS
.hero {
  background-image: url('./assets/hero.jpg');
}

// ═══ URL Assets — khusus untuk URL ═══
import imgUrl from './assets/img.png?url';
// imgUrl = '/assets/img.png' (raw URL, no processing)

// ═══ Raw Assets — sebagai string ═══
import shaderCode from './shaders/vertex.glsl?raw';
// shaderCode = isi file sebagai string

// ═══ Web Workers ═══
import Worker from './worker.js?worker';
const worker = new Worker();
worker.postMessage('Hello from main thread!');

// ═══ SVG as React Component ═══
// Dengan vite-plugin-svgr
import Logo from './assets/logo.svg?react';
<Logo className="app-logo" />

8. Environment Variables

Vite mendukung environment variables melalui file .env dan import.meta.env.

Text — Environment Files 
# .env — loaded di semua mode
VITE_APP_TITLE=BeebaneLabs Tutorial
VITE_API_URL=https://api.example.com

# .env.local — loaded di semua mode, gitignored
VITE_SECRET_TOKEN=my-secret

# .env.development — hanya di mode development
VITE_API_URL=http://localhost:3000/api

# .env.production — hanya di mode production
VITE_API_URL=https://api.beebanlabs.com/api

# .env.development.local — dev + local + gitignored

# ⚠️ PENTING: Hanya variabel yang diawali VITE_ yang
# bisa diakses di client-side kode!
# Variabel tanpa VITE_ hanya tersedia di vite.config.js
JavaScript — Menggunakan Env Variables 
// Menggunakan import.meta.env (tersedia di semua file .js/.ts)
console.log(import.meta.env.MODE);          // 'development' | 'production'
console.log(import.meta.env.PROD);          // true/false
console.log(import.meta.env.DEV);           // true/false
console.log(import.meta.env.SSR);           // true/false

// Custom env variables (harus diawali VITE_)
console.log(import.meta.env.VITE_APP_TITLE); // 'BeebaneLabs Tutorial'
console.log(import.meta.env.VITE_API_URL);   // 'https://api.example.com'

// Type safety untuk TypeScript
// src/env.d.ts
/// <reference types="vite/client" />
interface ImportMetaEnv {
  readonly VITE_APP_TITLE: string;
  readonly VITE_API_URL: string;
  readonly VITE_SECRET_TOKEN?: string;
}

interface ImportMeta {
  readonly env: ImportMetaEnv;
}

// Di vite.config.js — semua variabel tersedia
import { loadEnv } from 'vite';

export default defineConfig(({ mode }) => {
  const env = loadEnv(mode, process.cwd(), '');

  console.log(env.VITE_API_URL);    // ✅
  console.log(env.DATABASE_URL);    // ✅ (tanpa prefix juga bisa di sini)

  return {
    server: {
      proxy: {
        '/api': env.VITE_API_URL,
      },
    },
  };
});

Code Splitting

JavaScript — Code Splitting Configuration 
// vite.config.js
export default defineConfig({
  build: {
    rollupOptions: {
      output: {
        // Manual chunks — pisahkan vendor ke file terpisah
        manualChunks(id) {
          if (id.includes('node_modules')) {
            if (id.includes('react-dom')) {
              return 'vendor-react';
            }
            if (id.includes('lodash') || id.includes('date-fns')) {
              return 'vendor-utils';
            }
            return 'vendor'; // Sisanya ke vendor.js
          }
        },

        // Custom naming pattern
        entryFileNames: 'assets/js/[name]-[hash].js',
        chunkFileNames: 'assets/js/[name]-[hash].js',
        assetFileNames: 'assets/[ext]/[name]-[hash].[ext]',
      },
    },
  },
});

// Dynamic import — otomatis menjadi chunk terpisah
const HeavyModule = () => import('./HeavyModule.jsx');
const AdminPanel = () => import('./pages/AdminPanel.jsx');

SSR (Server-Side Rendering)

JavaScript — Vite SSR 
// server.js — Custom SSR server dengan Vite
import express from 'express';
import { createServer as createViteServer } from 'vite';

async function createServer() {
  const app = express();

  const vite = await createViteServer({
    server: { middlewareMode: true },
    appType: 'custom',
  });

  app.use(vite.middlewares);

  app.use('*', async (req, res) => {
    try {
      // Load entry point SSR
      const { render } = await vite.ssrLoadModule('/src/entry-server.jsx');

      // Render aplikasi ke HTML string
      const appHtml = await render(req.originalUrl);

      // Transform HTML dengan Vite
      const html = await vite.transformIndexHtml(req.originalUrl, `
        <!DOCTYPE html>
        <html>
        <head><title>SSR App</title></head>
        <body>
          <div id="root">${appHtml}</div>
          <script type="module" src="/src/entry-client.jsx"></script>
        </body>
        </html>
      `);

      res.status(200).set({ 'Content-Type': 'text/html' }).end(html);
    } catch (e) {
      vite.ssrFixStacktrace(e);
      console.error(e);
      res.status(500).end(e.message);
    }
  });

  app.listen(5173, () => {
    console.log('Server berjalan di http://localhost:5173');
  });
}

createServer();
