1. Pengenalan Astro

Astro adalah web framework all-in-one yang dirancang untuk membangun website yang cepat, content-driven. Filosofi utama Astro adalah "zero JavaScript by default" — halaman yang dibangun dengan Astro menghasilkan HTML murni tanpa JavaScript yang dikirim ke browser, kecuali Anda secara eksplisit memilih untuk menambahkannya.

Diciptakan oleh Fred K. Schott dan tim, Astro menjadi populer karena pendekatannya yang unik: Islands Architecture. Dengan Astro, Anda bisa menggunakan framework favorit Anda (React, Vue, Svelte, Preact, Solid, dll.) untuk komponen interaktif, sementara sisanya dirender sebagai HTML statis yang sangat cepat.

Mengapa Memilih Astro?

Keunggulan Penjelasan
Zero JS DefaultTidak mengirim JavaScript ke browser kecuali diperlukan — website sangat cepat
Framework AgnosticGunakan React, Vue, Svelte, Preact, Solid, atau vanilla JS dalam satu proyek

// Integrasi — tambahkan framework dan fitur
import react from '@astrojs/react';
import svelte from '@astrojs/svelte';
import tailwind from '@astrojs/tailwind';
import mdx from '@astrojs/mdx';

export default defineConfig({
  // Integrasi yang digunakan
  integrations: [
    react(),
    svelte(),
    tailwind(),
    mdx(),
  ],

  // Output mode
  // 'static' (default) — SSG, output HTML statis
  // 'server' — SSR, render di server
  // 'hybrid' — campuran, SSG default dengan SSR per halaman
  output: 'static',

  // Konfigurasi server
  server: {
    port: 4321,
    host: true,
  },

  // Build options
  build: {
    format: 'file', // 'file' atau 'directory'
  },

  // Vite config (Astro menggunakan Vite di belakang)
  vite: {
    plugins: [],
    css: {
      preprocessorOptions: {},
    },
  },
});

4. Islands Architecture

Islands Architecture adalah konsep kunci Astro. Bayangkan halaman web sebagai lautan HTML statis dengan "pulau-pulau" (islands) interaktif di dalamnya. Setiap island adalah komponen client-side yang hydrated secara terpisah — hanya island yang memerlukan interaktivitas yang mengirim JavaScript ke browser.

Client Directives

Directive Kapan Hydrate Gunakan Untuk
client:loadSaat halaman dimuat (segera)Komponen yang harus interaktif seketika
client:idleSaat browser idleKomponen yang tidak mendesak
client:visibleSaat komponen terlihat di viewportKomponen di bawah fold
client:mediaSaat media query terpenuhiKomponen khusus desktop/mobile
client:onlySkip SSR, render hanya di clientKomponen yang bergantung pada browser API
Astro — Menggunakan Islands 
---
// src/pages/index.astro
import Layout from '../layouts/Layout.astro';
import Card from '../components/Card.astro';

// Import komponen React (harus client directive)
import ReactCounter from '../components/ReactCounter.jsx';

// Import komponen Svelte
import SvelteSearch from '../components/SvelteSearch.svelte';

// Import komponen Vue
import VueModal from '../components/VueModal.vue';
---

<Layout title="Beranda">
  <!-- ✅ Static: tidak mengirim JS ke client -->
  <h1>Selamat Datang di BeebaneLabs</h1>
  <p>Ini adalah konten statis — zero JavaScript!</p>

  <!-- ✅ Static component -->
  <Card
    title="Tutorial React"
    description="Belajar React dari nol"
    href="/blog/react-dasar"
    tag="React"
  />

  <!-- ⚡ Island: React — hydrated SEGERA saat page load -->
  <ReactCounter client:load />

  <!-- ⚡ Island: Svelte — hydrated saat terlihat di viewport -->
  <SvelteSearch client:visible />

  <!-- ⚡ Island: Vue — hydrated saat browser idle -->
  <VueModal client:idle />

  <!-- ⚡ Island: hanya di mobile -->
  <SvelteSearch client:media="(max-width: 768px)" />

  <!-- ⚡ Island: skip SSR, hanya client -->
  <ReactCounter client:only="react" />

  <!-- ✅ Lebih banyak konten statis -->
  <p>Footer content — zero JavaScript lagi!</p>
</Layout>
JSX — ReactCounter.jsx (React Island) 
// src/components/ReactCounter.jsx
import { useState } from 'react';

export default function ReactCounter() {
  const [count, setCount] = useState(0);

  return (
    <div className="counter-island">
      <h3>⚡ React Island</h3>
      <p>Counter: {count}</p>
      <button onClick={() => setCount(c => c + 1)}>+</button>
      <button onClick={() => setCount(0)}>Reset</button>
    </div>
  );
}
Svelte — SvelteSearch.svelte (Svelte Island) 
<!-- src/components/SvelteSearch.svelte -->
<script>
  let query = '';
  let hasil = [];

  async function cari() {
    if (!query.trim()) return;
    const res = await fetch(`/api/search?q=${encodeURIComponent(query)}`);
    hasil = await res.json();
  }
</script>

<div class="search-island">
  <h3>⚡ Svelte Island — Search</h3>
  <input bind:value={query} placeholder="Cari..." on:keydown={(e) => e.key === 'Enter' && cari()} />
  <button on:click={cari}>🔍</button>

  {#if hasil.length}
    <ul>
      {#each hasil as item}
        <li>{item.title}</li>
      {/each}
    </ul>
  {/if}
</div>

5. Routing & Pages

Astro menggunakan file-based routing. Setiap file .astro, .md, atau .mdx di folder src/pages/ secara otomatis menjadi rute.

File Structure — Routing 
src/pages/
├── index.astro              → /
├── about.astro              → /about
├── blog/
│   ├── index.astro          → /blog
│   ├── [slug].astro         → /blog/react-dasar (dynamic)
│   └── [year]/
│       └── [month]/
│           └── [slug].astro → /blog/2026/06/react-dasar
├── api/
│   └── contact.ts           → /api/contact (API endpoint)
├── 404.astro                → Custom 404 page
└── [...slug].astro          → Catch-all route (fallback)

TypeScript — API Endpoint 
// src/pages/api/contact.ts
// API endpoint — mengembalikan JSON, bukan HTML
import type { APIRoute } from 'astro';

export const POST: APIRoute = async ({ request }) => {
  try {
    const data = await request.json();
    const { nama, email, pesan } = data;

    // Validasi
    if (!nama || !email || !pesan) {
      return new Response(
        JSON.stringify({ error: 'Semua field wajib diisi' }),
        { status: 400, headers: { 'Content-Type': 'application/json' } }
      );
    }

    // Proses data (simpan ke database, kirim email, dll.)
    console.log('Contact form:', { nama, email, pesan });

    return new Response(
      JSON.stringify({
        success: true,
        message: `Terima kasih, ${nama}! Pesan Anda sudah diterima.`,
      }),
      { status: 200, headers: { 'Content-Type': 'application/json' } }
    );
  } catch (error) {
    return new Response(
      JSON.stringify({ error: 'Internal server error' }),
      { status: 500, headers: { 'Content-Type': 'application/json' } }
    );
  }
};

// Juga bisa: GET, PUT, DELETE, PATCH
export const GET: APIRoute = () => {
  return new Response(
    JSON.stringify({ message: 'API contact berjalan' }),
    { status: 200 }
  );
};

7. Content Collections

Content Collections adalah fitur unggulan Astro untuk mengelola konten Markdown dan MDX dengan type-safety. Ini sangat cocok untuk blog, dokumentasi, dan website berbasis konten.

TypeScript — Definisi Collection (config.ts) 
// src/content/config.ts
import { defineCollection, z } from 'astro:content';

// Definisikan schema untuk collection blog
const blogCollection = defineCollection({
  type: 'content',
  schema: z.object({
    title: z.string(),
    description: z.string(),
    pubDate: z.coerce.date(),
    updatedDate: z.coerce.date().optional(),
    author: z.string().default('BeebaneLabs'),
    image: z.string().optional(),
    tags: z.array(z.string()).default([]),
    draft: z.boolean().default(false),
  }),
});

// Definisikan collection untuk pages
const pagesCollection = defineCollection({
  type: 'content',
  schema: z.object({
    title: z.string(),
    layout: z.string().default('page'),
  }),
});

// Export semua collections
export const collections = {
  blog: blogCollection,
  pages: pagesCollection,
};

9. SSR & Middleware

Selain SSG, Astro mendukung Server-Side Rendering (SSR) untuk halaman yang memerlukan data real-time atau autentikasi.

TypeScript — Middleware 
// src/middleware.ts
import { defineMiddleware } from 'astro:middleware';

// Middleware berjalan sebelum halaman di-render
export const onRequest = defineMiddleware(async (context, next) => {
  const url = new URL(context.request.url);
  console.log(`[Middleware] ${context.request.method} ${url.pathname}`);

  // Autentikasi
  const token = context.cookies.get('auth-token');
  const isAuthenticated = !!token?.value;

  // Proteksi route
  if (url.pathname.startsWith('/dashboard') && !isAuthenticated) {
    return context.redirect('/login');
  }

  // Tambahkan data ke locals (tersedia di semua halaman)
  context.locals.user = isAuthenticated ? { loggedIn: true } : null;
  context.locals.requestTime = new Date().toISOString();

  // Lanjutkan ke handler berikutnya
  const response = await next();

  // Modifikasi response jika perlu
  response.headers.set('X-Request-Time', context.locals.requestTime);

  return response;
});
