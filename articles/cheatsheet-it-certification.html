CCNA 200-301 Topics

20% - Network Fundamentals
  - OSI model, TCP/IP, IPv4/IPv6, Subnetting

  - VLANs, STP, EtherChannel, Wireless

10% - IP Services
  - DHCP, DNS, NTP, SNMP, QoS
15% - Security Fundamentals
  - ACLs, port security, VPN, wireless security
10% - Automation & Programmability
  - REST APIs, SDN, Ansible, JSON/YAML

7. Tips Ujian

AspekTips
PersiapanBuat jadwal belajar konsisten 1-2 jam/hari selama 8-12 minggu
PersiapanGunakan multiple sumber: video + buku + practice test
PersiapanBuat cheat sheet sendiri saat belajar (proses menulis bantu ingat)
Practice TestTarget skor 85%+ sebelum ujian sesungguhnya
Practice TestReview penjelasan jawaban yang salah, bukan cuma skor
Saat UjianBaca soal dengan teliti — perhatikan kata "MOST", "LEAST", "BEST"
Saat UjianEliminasi jawaban yang jelas salah terlebih dahulu
Saat UjianJangan terlalu lama di 1 soal — tandai dan kembali nanti
Saat UjianSimpan 10-15 menit terakhir untuk review
PsikologisTidur cukup malam sebelum ujian
Online ProctorPastikan koneksi stabil, ruangan rapi, tidak ada catatan

1. Ikuti tutorial, lalu coba ulang tanpa melihat instruksi
2. Buat project portofolio dari hasil lab
3. Dokumentasikan setup di GitHub (README + screenshots)
4. Gabungkan beberapa layanan dalam 1 mini project
5. Ambil challenge: rebuild environment dari scratch
