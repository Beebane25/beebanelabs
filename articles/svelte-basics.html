1. Pengenalan Svelte

Svelte adalah framework JavaScript yang revolusioner — berbeda dari React atau Vue, Svelte melakukan sebagian besar pekerjaan di waktu kompilasi (compile time), bukan di runtime. Ini berarti aplikasi Svelte menghasilkan bundle yang sangat kecil dan performa yang luar biasa cepat.

Diciptakan oleh Rich Harris pada tahun 2016, Svelte menawarkan pendekatan yang berbeda: alih-alih menggunakan Virtual DOM, Svelte mengkompilasi komponen Anda menjadi kode JavaScript vanilla yang sangat efisien yang memperbarui DOM secara langsung.

Mengapa Svelte Berbeda?

Aspek React / Vue Svelte
PendekatanRuntime (Virtual DOM)Compile-time (No Virtual DOM)
Bundle Size42-143 KB (framework runtime)~2 KB (tanpa runtime)
ReactivityuseState / ref() — explicitReassignment otomatis
Boilerplate🟡 Sedang-Sedang🟢 Sangat Sedikit
Performance🟡 Bagus (perlu optimasi)🟢 Sangat Cepat (built-in)
Learning Curve🟡 Sedang🟢 Mudah

Keunggulan Svelte

💡 Mengapa Memilih Svelte?

1. Zero Runtime — Svelte dikompilasi menjadi vanilla JS, sehingga tidak perlu meng-ship framework runtime ke browser. 2. Kode Lebih Sedikit — Menulis fitur yang sama di Svelte membutuhkan ~40% lebih sedikit kode dibanding React. 3. Reaktivitas Built-in — Ubah variabel, UI otomatis ter-update tanpa setter function. 4. SvelteKit — Meta-framework untuk SSR, routing, dan full-stack development.

💡 Keunggulan Svelte

Di Svelte, Anda tidak perlu useState, ref(), atau computed(). Cukup ubah variabel — Svelte compiler akan mendeteksi reassignment dan meng-update DOM secara otomatis. Ini membuat kode jauh lebih natural dan mudah dibaca.

4. Reactivity

Reaktivitas di Svelte terjadi secara otomatis saat Anda meng-assign ulang variabel. Ini adalah fitur paling powerful dan elegan dari Svelte.

Reactive Declarations

Svelte — Reactivity Dasar 
<script>
  // State biasa — reactive saat di-assign ulang
  let count = 0;
  let nama = 'Svelte';

  // Reactive declaration ($:) — otomatis update saat dependensi berubah
  $: doubled = count * 2;
  $: tripled = count * 3;
  $: greeting = `Halo, ${nama}! Count: ${count}`;

  // Reactive statement — blok kode yang dijalankan saat deps berubah
  $: {
    console.log(`Count berubah: ${count}`);
    console.log(`Doubled: ${doubled}`);
  }

  // Reactive perbandingan
  $: isPositive = count > 0;
  $: isEven = count % 2 === 0;

  function increment() {
    count += 1;  // ← Langsung reactive, tidak perlu setter!
  }

  function decrement() {
    count -= 1;
  }

  function reset() {
    count = 0;
  }
</script>

<div class="counter">
  <h2>{greeting}</h2>

  <div class="stats">
    <span>Count: {count}</span>
    <span>Doubled: {doubled}</span>
    <span>Tripled: {tripled}</span>
    <span>Genap: {isEven ? 'Ya' : 'Tidak'}</span>
  </div>

  <div class="controls">
    <button on:click={decrement}>−</button>
    <button on:click={reset}>Reset</button>
    <button on:click={increment}>+</button>
  </div>
</div>

Reactivity dengan Array dan Object

Svelte — Array & Object Reactivity 
<script>
  let items = ['Apel', 'Pisang', 'Ceri'];
  let newItem = '';

  // ⚠️ Di Svelte, reassignment langsung reaktif
  // Berbeda dengan Vue/React yang perlu method khusus

  function tambahItem() {
    if (newItem.trim()) {
      items = [...items, newItem.trim()]; // Reassignment = reactive!
      newItem = '';
    }
  }

  function hapusItem(index) {
    items = items.filter((_, i) => i !== index); // Reactive!
  }

  // Array methods yang memicu reactivity:
  // items = items.concat('Durian');      ✅
  // items = [...items, 'Durian'];        ✅
  // items = items.filter(...);           ✅
  // items = items.map(...);              ✅
  // items = items.slice(...);            ✅
  // items.splice(0, 1); items = items;  ✅ (perlu reassign!)
  // items.push('Durian'); items = items; ✅ (perlu reassign!)

  // Object reactivity
  let user = { nama: 'Budi', umur: 25 };

  function tambahUmur() {
    user = { ...user, umur: user.umur + 1 }; // Spread = reactive!
    // ⚠️ user.umur += 1; TIDAK reactive di Svelte 3
    // Di Svelte 5 dengan runes, ini bisa reactive
  }
</script>

<div>
  <input bind:value={newItem} placeholder="Tambah item..." />
  <button on:click={tambahItem}>Tambah</button>

  <ul>
    {#each items as item, i}
      <li>
        {item}
        <button on:click={() => hapusItem(i)}>✕</button>
      </li>
    {/each}
  </ul>

  <p>Total: {items.length} item</p>

  <div>
    <p>{user.nama}, umur {user.umur}</p>
    <button on:click={tambahUmur}>Tambah Umur</button>
  </div>
</div>

5. Props dan Data Flow

Props di Svelte dideklarasikan dengan export let di dalam <script>. Ini mungkin terlihat aneh bagi yang terbiasa ES Modules, tapi ini adalah cara Svelte menandai bahwa variabel tersebut bisa di-set dari luar.

Svelte — Card.svelte (Menerima Props) 
<!-- Card.svelte -->
<script>
  // Props — di-export dari komponen, bisa di-set dari parent
  export let judul = 'Judul Default';
  export let deskripsi = '';
  export let warna = '#3b82f6';
  export let tersedia = false;

  // Default value di-deklarasikan langsung di export

<div class="card" style="border-color: {warna}">
  <h3 style="color: {warna}">{judul}</h3>
  {#if deskripsi}

  {/if}
  {#if tersedia}
    <span class="badge">✅ Tersedia</span>
  {:else}
    <span class="badge unavailable">❌ Tidak Tersedia</span>
  {/if}
</div>

6. Events

Svelte memiliki sistem event yang unik — menggunakan createEventDispatcher untuk mengirim custom events dari child ke parent.

Svelte — Custom Events 
<!-- SearchBar.svelte -->
<script>
  import { createEventDispatcher } from 'svelte';

  const dispatch = createEventDispatcher();
  let query = '';

  function handleSearch() {
    // Kirim event ke parent
    dispatch('search', {
      query: query,
      timestamp: Date.now()
    });
  }

  function handleClear() {
    query = '';
    dispatch('clear');
  }

  // Event forwarding dengan on:click
  // Komponen bisa me-forward event DOM ke parent
</script>

<div class="search-bar">
  <input
    bind:value={query}
    placeholder="Cari sesuatu..."
    on:keydown={(e) => e.key === 'Enter' && handleSearch()}
  />
  <button on:click={handleSearch}>🔍 Cari</button>
  {#if query}
    <button on:click={handleClear}>✕</button>
  {/if}
</div>
Svelte — Mendengarkan Events di Parent 
<!-- App.svelte -->
<script>
  import SearchBar from './lib/SearchBar.svelte';

  let hasil = '';

  function handleSearch(event) {
    // event.detail berisi data yang dikirim dari dispatch()
    const { query, timestamp } = event.detail;
    hasil = `Mencari: "${query}" pada ${new Date(timestamp).toLocaleTimeString()}`;
    // Di sini bisa panggil API, filter data, dll.
  }

  function handleClear() {
    hasil = '';
  }
</script>

<main>
  <SearchBar
    on:search={handleSearch}
    on:clear={handleClear}
  />

  {#if hasil}
    <p class="hasil">{hasil}</p>
  {/if}
</main>

7. Conditional Rendering & Loops

Svelte menggunakan blok template spesial dengan sintaks {#if}, {#each}, dan {#await}.

Svelte — Conditional Rendering 
<script>
  let status = 'loading'; // 'loading', 'success', 'error'
  let data = null;
  let errorMsg = '';

  async function fetchData() {
    status = 'loading';
    try {
      const res = await fetch('https://jsonplaceholder.typicode.com/users/1');
      data = await res.json();
      status = 'success';
    } catch (err) {
      errorMsg = err.message;
      status = 'error';
    }
  }
</script>

<!-- {#if} / {:else if} / {:else} -->
{#if status === 'loading'}
  <div class="loading">⏳ Memuat data...</div>
{:else if status === 'success'}
  <div class="success">
    <h2>✅ {data.name}</h2>
    <p>Email: {data.email}</p>
    <p>Kota: {data.address?.city}</p>
  </div>
{:else}
  <div class="error">
    <p>❌ Error: {errorMsg}</p>
    <button on:click={fetchData}>Coba Lagi</button>
  </div>
{/if}

<button on:click={fetchData}>Muat Data</button>
Svelte — Each Loops 
<script>
  let todos = [
    { id: 1, text: 'Belajar Svelte', done: true },
    { id: 2, text: 'Buat proyek', done: false },
    { id: 3, text: 'Deploy ke production', done: false },
  ];

  let inputText = '';
  let nextId = 4;

  function tambahTodo() {
    if (inputText.trim()) {
      todos = [...todos, { id: nextId++, text: inputText, done: false }];
      inputText = '';
    }
  }

  function toggleTodo(id) {
    todos = todos.map(t =>
      t.id === id ? { ...t, done: !t.done } : t
    );
  }

  function hapusTodo(id) {
    todos = todos.filter(t => t.id !== id);
  }

  // Reactive: hitung jumlah selesai
  $: selesai = todos.filter(t => t.done).length;
</script>

<div>
  <input bind:value={inputText} placeholder="Todo baru..." />
  <button on:click={tambahTodo}>Tambah</button>

  <!-- {#each} dengan key (seperti React key) -->
  {#each todos as todo (todo.id)}
    <div class="todo" class:selesai={todo.done}>
      <input
        type="checkbox"
        checked={todo.done}
        on:change={() => toggleTodo(todo.id)}
      />
      <span>{todo.text}</span>
      <button on:click={() => hapusTodo(todo.id)}>🗑</button>
    </div>
  {:else}
    <p>Belum ada todo. Tambahkan yang baru!</p>
  {/each}

  <p>{selesai}/{todos.length} selesai</p>
</div>

<style>
  .todo { display: flex; gap: 8px; align-items: center; padding: 8px; }
  .selesai span { text-decoration: line-through; opacity: 0.6; }
</style>

  async function fetchUsers() {

8. Stores (State Management)

Stores di Svelte adalah reactive data containers yang bisa di-share antar komponen. Mereka menyediakan cara sederhana dan elegan untuk global state management tanpa library tambahan.

Tiga Jenis Store

Svelte — stores.js (Writable, Readable, Derived) 
// lib/stores.js
import { writable, readable, derived } from 'svelte/store';

// ─── WRITABLE STORE ───
// Bisa di-read dan di-write dari mana saja
export const count = writable(0);
export const nama = writable('Budi');
export const todos = writable([]);

// ─── READABLE STORE ───
// Hanya bisa di-read (nilai dikontrol oleh store)
export const waktu = readable(new Date(), function start(set) {
  const interval = setInterval(() => {
    set(new Date());
  }, 1000);

  return function stop() {
    clearInterval(interval);
  };
});

// ─── DERIVED STORE ───
// Nilai di-derive dari store lain
export const greeting = derived(nama, ($nama) => {
  const jam = new Date().getHours();
  if (jam < 11) return `Selamat pagi, ${$nama}! 🌅`;
  if (jam < 15) return `Selamat siang, ${$nama}! ☀️`;
  if (jam < 18) return `Selamat sore, ${$nama}! 🌇`;
  return `Selamat malam, ${$nama}! 🌙`;
});

// Derived dari multiple stores
export const countStats = derived(
  [count],
  ([$count]) => ({
    value: $count,
    doubled: $count * 2,
    isPositive: $count > 0,
    isEven: $count % 2 === 0,
  })
);
Svelte — Menggunakan Stores 
<!-- Counter.svelte -->
<script>
  import { count, countStats } from './lib/stores.js';

Custom Store

Svelte — Custom Store dengan Methods 
// lib/todoStore.js
import { writable, derived } from 'svelte/store';

function createTodoStore() {
  const { subscribe, set, update } = writable([]);

  return {
    subscribe,

    tambah(text) {
      update(todos => [
        ...todos,
        { id: Date.now(), text, done: false, createdAt: new Date() }
      ]);
    },

    toggle(id) {
      update(todos =>
        todos.map(t => t.id === id ? { ...t, done: !t.done } : t)
      );
    },

    hapus(id) {
      update(todos => todos.filter(t => t.id !== id));
    },

    hapusSemuaSelesai() {
      update(todos => todos.filter(t => !t.done));
    },

    reset() {
      set([]);
    }
  };
}

export const todoStore = createTodoStore();

// Derived: statistik

9. Lifecycle Hooks

Svelte menyediakan beberapa lifecycle hooks untuk menjalankan kode pada momen-momen penting dalam siklus hidup komponen.

Hook Dipanggil Saat Gunakan Untuk
onMountSetelah komponen pertama kali dirender ke DOMFetch data, setup DOM, event listener
onDestroySebelum komponen dihapus dari DOMCleanup: hapus listener, cancel timer
beforeUpdateSebelum DOM di-updateScroll position, caching
afterUpdateSetelah DOM di-updateScroll to bottom, focus
tickSetelah state update selesai dan DOM flushedRead DOM state setelah update
Svelte — Lifecycle Hooks Lengkap 
<script>
  import { onMount, onDestroy, beforeUpdate, afterUpdate, tick } from 'svelte';

  let messages = [];
  let inputText = '';
  let chatContainer;
  let autoscroll = false;

  // onMount — jalankan saat komponen masuk DOM
  onMount(() => {
    console.log('Komponen mounted!');
    fetchMessages();

    // Setup interval
    const interval = setInterval(fetchMessages, 5000);

    // onDestroy — kembalikan fungsi cleanup ( shorthand)
    return () => {
      console.log('Komponen destroyed, cleanup...');
      clearInterval(interval);
    };
  });

  // onDestroy secara eksplisit
  onDestroy(() => {
    console.log('Cleanup resources');
  });

  // beforeUpdate — sebelum DOM update
  beforeUpdate(() => {
    // Cek apakah user scroll ke bawah sebelum update
    if (chatContainer) {
      const scrollBottom = chatContainer.scrollHeight - chatContainer.scrollTop;
      autoscroll = scrollBottom < chatContainer.clientHeight + 50;
    }
  });

  // afterUpdate — setelah DOM update
  afterUpdate(() => {
    // Auto-scroll ke bawah jika sebelumnya di bawah
    if (autoscroll && chatContainer) {
      chatContainer.scrollTo(0, chatContainer.scrollHeight);
    }
  });

  async function fetchMessages() {
    // Simulasi fetch
    const newMsg = {
      id: Date.now(),
      text: `Pesan #${messages.length + 1}`,
      time: new Date().toLocaleTimeString('id-ID'),
    };
    messages = [...messages, newMsg];

    // Tunggu DOM update selesai
    await tick();
    console.log('DOM sudah update setelah menambah pesan');
  }
</script>

<div class="chat">
  <div class="messages" bind:this={chatContainer}>
    {#each messages as msg (msg.id)}
      <div class="message">
        <span class="time">{msg.time}</span>
        <span>{msg.text}</span>
      </div>
    {/each}
  </div>

  <div class="input-area">
    <input bind:value={inputText} placeholder="Ketik pesan..." />
    <button on:click={fetchMessages}>Kirim</button>
  </div>
</div>

10. Animations & Transitions

Salah satu fitur terbaik Svelte adalah sistem animasi dan transisi built-in. Svelte menyediakan transitions (saat elemen masuk/keluar DOM), animations (saat elemen berubah posisi), dan motion (tweened/spring values).

Transitions (In/Out)

Svelte — Built-in Transitions 
<script>
  import { fade, fly, slide, scale, blur } from 'svelte/transition';
  import { flip } from 'svelte/animate';
  import { quintOut } from 'svelte/easing';

  let visible = true;
  let items = [
    { id: 1, text: 'Belajar Svelte', done: false },
    { id: 2, text: 'Buat animasi', done: false },
    { id: 3, text: 'Deploy app', done: false },
  ];

  function toggleVisibility() {
    visible = !visible;
  }

  function hapusItem(id) {
    items = items.filter(i => i.id !== id);
  }

  function acakUrutan() {
    items = [...items].sort(() => Math.random() - 0.5);
  }
</script>

<!-- Fade transition -->
<button on:click={toggleVisibility}>Toggle</button>

{#if visible}
  <div
    transition:fade={{ duration: 300 }}
    class="panel"
  >
    <h3>Panel ini fade in/out</h3>
  </div>
{/if}

<!-- Fly transition -->
{#if visible}
  <div
    transition:fly={{ y: 200, duration: 500, easing: quintOut }}
    class="panel"
  >
    <h3>Panel ini terbang dari bawah</h3>
  </div>
{/if}

<!-- Scale transition -->
{#if visible}
  <div
    in:scale={{ duration: 300, start: 0.5 }}
    out:fade={{ duration: 200 }}
    class="panel"
  >
    <h3>Scale in, fade out</h3>
  </div>
{/if}

    class="item"
  >
    <span>{item.text}</span>
    <button on:click={() => hapusItem(item.id)}>✕</button>
  </div>
{/each}

Custom Transition

Svelte — Custom Transition Function 
<script>
  // Custom transition: typewriter effect
  function typewriter(node, { speed = 50 }) {
    const text = node.textContent;
    const duration = text.length * speed;

    return {
      duration,
      tick(t) {
        const i = Math.trunc(text.length * t);
        node.textContent = text.slice(0, i);
      }
    };
  }

  // Custom transition: rotate in
  function rotateIn(node, { duration = 400, delay = 0 }) {
    return {
      duration,
      delay,
      css: t => {
        const eased = t * t; // ease-in
        return `
          transform: rotate(${(1 - eased) * 360}deg);
          opacity: ${t};
        `;
      }
    };
  }

  let show = false;
</script>

<button on:click={() => show = !show}>Toggle</button>

{#if show}
  <p transition:typewriter={{ speed: 30 }}>
    Ini akan diketik huruf per huruf seperti mesin tik!
  </p>

  <div in:rotateIn={{ duration: 600 }}>
    <p>Rotasi masuk! 🌀</p>
  </div>
{/if}
